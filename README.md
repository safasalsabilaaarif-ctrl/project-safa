# Project Portofolio - Safa

Website portofolio sederhana dan responsif yang dibangun menggunakan HTML dan CSS modern.

## 🚀 Fitur
- Desain modern, bersih, dan estetik dengan nuansa dark mode.
- Tata letak responsif (mobile-friendly).
- Bagian Profil (Hero), Tentang Saya, Keahlian (Skills), Portofolio Proyek, dan Kontak.
- Efek transisi halus dan styling CSS murni tanpa framework tambahan.

## 📂 Struktur File
```text
project Safa/
├── Safa.html        # Halaman utama portofolio
└── README.md        # Dokumentasi proyek
```

## 💻 Cara Menjalankan
Cukup buka file `Safa.html` langsung di browser favorit Anda (Google Chrome, Edge, Firefox, dll).
